# Improve Selector Guide

> Retired. Kept so existing links to this path keep resolving.

To improve a target selector, go through the [`uia-configure-target`](../skills/uia-configure-target/SKILL.md) skill — selector hardening happens inside its TARGET-7.2 step, as part of the normal configure flow ([Configure Target Guide](uia-configure-target-guide.md)). Otherwise consider the target as no longer valid and run the recovery process on it.

To recover an existing target that is no longer valid, reference [uia-recover-selector-guide.md](uia-recover-selector-guide.md).
